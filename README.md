# Hamster Skills

Hamster's catalog of product-development methods and the skills that put them into practice, in the shape that [agentskills.io](https://agentskills.io)-compatible tools — Codex, Claude Code, Cursor, and the `npx skills` CLI — expect. Each method is a written account of an operating model; each skill is a self-contained instruction set an agent can run.

## Install

Install every skill interactively:

```sh
npx skills add gethamster/skills
```

Install a single skill non-interactively for a specific agent:

```sh
npx skills add gethamster/skills --skill <name> --agent codex --yes
```

## Layout

- `skills/<skill>/SKILL.md` is an installable skill. Its frontmatter names the method it belongs to under `metadata.method` and repeats that method's `category`.
- `methods/<method>/METHOD.md` is the method write-up — published for reading, to understand the operating model a group of skills belongs to. It is not installable.
- `skills/.experimental/<skill>/SKILL.md` is the contributor lane for standalone skills that do not belong to a method yet; see [Contributing](#contributing).
- `skills.sh.json` groups the skills by category for [skills.sh](https://skills.sh), one section per category, with each method's category declared in its `METHOD.md`. It and the catalog table below are generated from the files above by `scripts/generate-catalog-manifest.mjs`.
