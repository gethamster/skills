# RICE Framework

> Created by **Intercom** — [https://www.intercom.com/blog/rice-simple-prioritization-for-product-managers](https://www.intercom.com/blog/rice-simple-prioritization-for-product-managers)

The RICE framework is a product prioritization model developed at Intercom. It scores initiatives across four dimensions — **Reach**, **Impact**, **Confidence**, and **Effort** — to produce a single comparable number.

## Formula

```
RICE Score = (Reach × Impact × Confidence) ÷ Effort
```

## Dimensions

| Dimension | Unit | Scale |
|-----------|------|-------|
| Reach | Users per quarter | Open (e.g., 500, 10,000) |
| Impact | Multiplier | 0.25, 0.5, 1, 2, 3 |
| Confidence | Percentage | 50%, 80%, 100% |
| Effort | Person-months | Open (e.g., 0.5, 3, 6) |

## When to Use

- Comparing 10-50 discrete initiatives in a product backlog
- Cross-functional teams needing a shared prioritization language
- Surfacing quick wins hidden among large strategic bets

## When Not to Use

- Regulatory or compliance work with hard deadlines
- Very early-stage products where strategy pivots weekly
- Purely technical work with no end-user impact
