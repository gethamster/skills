# Security Policy

## Reporting a vulnerability

Please do not report security problems through GitHub issues or pull requests.

Email hello@tryhamster.com and the maintainers will pick it up. Hamster's security posture and SOC 2 report requests live at [trust.tryhamster.com](https://trust.tryhamster.com).

## What counts as a vulnerability here

Skills in this catalog are instructions that an agent executes on your behalf. Beyond ordinary code and supply-chain issues, please report skill content that amounts to prompt injection — hidden instructions that exfiltrate data, escalate privileges, or otherwise act outside what the skill advertises — or that directs the agent to run destructive commands without clear warning. Report these to the same address.
