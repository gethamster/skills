# FAQ: Claude AI Prompts Built on Constitutional Values

## Do I need to mention the constitution in my prompts?

No. Claude is trained with the constitution already. What helps is writing prompts that give it the context the constitution assumes it will have: the goal, the reader, the sources and the reasons for your constraints.

## Will Claude write persuasive marketing copy?

Yes. The constitution treats persuasive writing on request as a performative assertion, which does not break its honesty norms, though Claude may add a note that the piece is one-sided. It does not extend to fabricated facts, so supply the evidence you want the copy to use.

## Why does Claude flag claims in my drafts?

It is meant to be truthful and calibrated, which includes acknowledging when it cannot support a statement. A flag usually means the prompt asked for a claim without providing a source. Add the source or remove the claim.

## Where should keywords go in a Claude AI prompt?

Put them in the constraints section with a reason, and ask for natural use in the title, opening paragraph and a heading. Avoid asking for a fixed number of repetitions, which harms readability and moves toward keyword stuffing. Google's own guidance says keyword stuffing is against its spam policies.

## Should context go in the system prompt or the user message?

Put durable context such as your business, audience and standards in the system prompt, where an operator would put it. Put the specific task, topic and sources in the user message. That keeps templates reusable and each request short.
