# FAQ: How to Create a Customer Journey Map That Drives Action

## How do I build a journey map when I have very little customer data?

Start with what you have: support tickets, sales notes, reviews and basic funnel analytics already contain a lot of customer language. Add a small number of short interviews focused on specific moments rather than general opinions. Mark every cell that rests on assumption so the team knows what still needs checking. A map with honest gaps is more useful than one that fills every cell with guesses.

## How long should the mapping session be?

Long enough to cover every stage without rushing, and short enough that people stay engaged. Many teams run a half-day session, or split a complex journey into two sessions, one for the stages before purchase and one for after. Most of the time on a first map goes into research before the session and cleanup after it. Budget for both.

## Should I map touchpoints before building the journey map?

Build the journey map first to set the stages, the actor and the emotional arc. Then use a touchpoint inventory to fill in each stage in detail. Starting with a touchpoint list tends to produce a long catalog without context about when each interaction happens or how it feels. The two artifacts work best linked together.

## What format should the map use?

Use whatever the team already opens during planning: a digital whiteboard, a shared document or a spreadsheet. The format matters less than keeping the map to one readable page with stages as columns. Avoid tools that only one person can edit, because the map needs updating by stage owners. A physical wall is fine for the session but should be digitized afterward.

## How is a journey map different from a service blueprint?

A journey map shows the customer's view: what they do, think and feel at each stage. A service blueprint adds what the organization does behind each touchpoint, including frontstage staff actions, backstage work and supporting systems. Use a journey map to find where the experience breaks and a blueprint to fix the internal work behind a specific break.
