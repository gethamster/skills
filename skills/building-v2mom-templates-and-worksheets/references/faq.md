# FAQ: Building V2MOM Templates and Worksheets

## Should every level use the same template?

Use the same five headings in the same order at every level, so documents can be read against each other. The number of fields can differ: company and department templates may need full measures tables and obstacle owners, while an individual version can be lighter. The structure is the part that must match.

## What tool should hold the template?

Any tool the whole organization can read and copy from works, such as a shared document space or wiki. The finished V2MOMs should live in the same place so readers can follow links between levels. Pick the tool people already use rather than introducing a new one for V2MOM alone.

## Should the template include instructions?

Include short prompts under each heading, written so authors can delete them once they have filled the section in. Put longer guidance in a separate page linked from the template. Long instructions inside the template end up copied into finished documents and make them harder to read.

## How do we stop teams from drifting to their own formats?

Keep one canonical template, version it and link to it from wherever the cascade is announced. Review a few documents early in each cycle and point authors back to the template if they have changed the structure. If several teams make the same change, consider adopting it in the template.

## Is a worked example necessary?

It helps a great deal. Most people learn a format faster from a filled-in page than from prompts. Make the example clearly invented so nobody mistakes it for a real team's plan, and use it to show the difference between strong and weak entries.
