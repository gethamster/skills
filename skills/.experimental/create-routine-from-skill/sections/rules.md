## Rules

- Honest no's beat forced automations. "This skill should stay manual" is a valid, complete output.
- The prompt is verbatim and pasteable. No "[insert details here]" inside the prompt itself; unresolved items go in Open items.
- Third-party skills: the routine is the Hamster upgrade of a skill people already love. Name the original creator in the spec so the eventual article credits them.
- Never invent trigger types, config fields, or Hamster mechanics. Three shapes (schedule, trigger, loop/goal) unless the live docs say otherwise at spec time.
