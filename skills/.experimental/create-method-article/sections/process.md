## Process

1. Map source pack + component inventory onto the anatomy.
2. Draft per the anatomy, image slots inline as `[IMG-nn — orientation: description]`.
3. Extract the shot list. The method-flow diagram is mandatory and listed first; note it may need to be designed, not just captured.
4. List gaps: unverified components, missing deep-dive links, unconfirmed sequence points.
5. Run the anatomy checklist.
