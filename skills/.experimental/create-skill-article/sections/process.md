## Process

1. Map the source pack onto the anatomy: which posts prove the pain, which prior art gets credited, what grounds the proposal.
2. Draft section by section per the anatomy. Prose between visuals: 3 sentences max. Where an image goes, insert a bracketed image slot: `[IMG-03 — wide: /command invoked in Hamster chat, response streaming below]`.
3. Extract the shot list: every `[IMG-nn]` slot, numbered, with what the capture must show and orientation. This is Eyal's capture checklist.
4. List source gaps: any claim still standing on nothing (no post, no screenshot possible). The article does not publish with open gaps.
5. Run the checklist at the bottom of `references/article-anatomy.md`. Fix failures before presenting.
