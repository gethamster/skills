## Rules

- **Real posts only.** Never fabricate, reconstruct from memory, or "approximate" a quote. If search comes up dry, say so in Gaps. A thin honest pack beats a padded fake one.
- **Verbatim capture.** The article embeds posts; paraphrase is useless.
- **Recency matters.** Prefer posts from the last 6 months unless an older post is canonical (a famous complaint, the original launch of a skill).
- **X longform can only embed X posts.** Reddit finds get quoted as text with a link, so note the platform on every item.
- **No engagement-number claims.** Describe a post as "widely shared" only if you verified it; never invent counts.
