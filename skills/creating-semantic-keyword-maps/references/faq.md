# FAQ: Semantic Keyword Mapping for Pillar Content

## What is semantic keyword mapping?

It is assigning keywords to pages by meaning and intent. Keywords that searchers use for the same need go to one page, and keywords for different needs go to different pages. The result is a table of groups, their intent and their target pages.

## How do I decide whether two keywords belong on the same page?

Compare their search results. If Google ranks mostly the same pages for both, they share an intent and one page should target them. If the results show different kinds of pages, such as guides for one and product pages for the other, give them separate pages.

## Do I need a clustering tool?

Tools save time on long lists by comparing search results automatically. For a small list, or for borderline pairs, reading the results yourself works and is often more accurate. In both cases, a person should review the groups before pages are assigned.

## How does the keyword map relate to the cluster architecture?

The map says which groups exist and which page serves each. The architecture arranges those pages into a pillar and cluster structure with URLs and internal links. Build the map first, then the architecture.

## How often should the map be updated?

Update it whenever you publish, merge or retire a page, and review it every quarter with fresh Search Console queries. New queries either join an existing group or reveal a group that needs a page.
