# FAQ: Types of MVP: How to Choose the Right Format

## What are the main types of MVP?

Common types include the landing page, the explainer video, the concierge MVP, the Wizard of Oz MVP, the piecemeal MVP and the single-feature MVP. Some guides add email and prototype MVPs. Each suits a different question, from whether anyone wants the product to whether they keep using it.

## What is a Wizard of Oz MVP?

It is an MVP that looks like a working, automated product to the customer while people do the work behind the scenes. It lets you test how customers respond to the experience before building the technology. The name comes from human-computer interaction research, where a hidden operator simulated a system that participants believed was automated.

## What is a piecemeal MVP?

A piecemeal MVP combines existing tools and services to deliver the full offer without building new technology. A website builder, a form tool, a payment link and a spreadsheet can together run a real service. It is a good choice when you need to test the whole experience end to end at low cost.

## Is a landing page really an MVP?

It can be, when it measures a real customer action that bears on your riskiest assumption. A landing page tests whether people want what you describe, which is often the first question to answer. It does not test whether the product delivers value, so it is usually followed by another type.

## How many MVP types should we try?

As many as the questions require, one at a time. Most products move from demand tests to value tests to tests of sustained use. Each passed test tells you which type to use next.
