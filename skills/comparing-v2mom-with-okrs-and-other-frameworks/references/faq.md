# FAQ: V2MOM vs OKRs and Other Goal-Setting Frameworks

## What is the main difference between V2MOM and OKRs?

V2MOM focuses on direction and tradeoffs: it asks for a vision, ranked values, ranked methods, explicit obstacles and measures. OKRs focus on execution: a few objectives with measurable key results, usually set and scored quarterly. V2MOM tells people which priority wins, and OKRs track whether the chosen priorities are being delivered.

## Can we use V2MOM and OKRs together?

Yes, and it is a common pairing. Use V2MOM for the year's direction and OKRs for each quarter's execution. Have each OKR objective cite the V2MOM method it serves, and link the documents instead of copying text between them.

## Where does the balanced scorecard fit?

The balanced scorecard, introduced by Kaplan and Norton, is a measurement system that looks at performance from several perspectives beyond finances. It can inform the measures section of a V2MOM, especially at the company level, by making sure measures are not all financial. It does not replace the direction-setting parts of V2MOM.

## What is Hoshin Kanri and how does it compare?

Hoshin Kanri is a lean approach to deploying strategy through an organization, with catchball as its core practice: goals pass down, feedback passes back up and the levels negotiate until the plan is both aligned and feasible. V2MOM cascades can borrow catchball directly by having managers review drafts from below and revising the parent V2MOM when drafts reveal problems.

## When is no formal framework the right choice?

When a team is small, shares context every day and agrees on priorities, a formal framework adds process without solving a problem. A single one-page V2MOM can still help founders rank priorities and name risks. Add structure when teams start making decisions that contradict each other.
