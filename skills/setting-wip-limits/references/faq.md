# FAQ: Setting WIP Limits in Kanban

## What is a good starting WIP limit?

There is no universal number. A practical first guess ties each limit to the capacity of the stage, such as the number of people who work in it, and then adjusts from observation. Start slightly tighter than feels comfortable, because a limit that is never reached does not change behavior. Treat the first numbers as an experiment you will revisit within a few weeks.

## Should blocked items count against the limit?

In most cases, yes. If blocked items do not count, the team can keep starting new work while blocked items pile up, which hides the problem the limit is meant to expose. Some teams put blocked items in a visible holding area with its own small limit. Whatever you choose, write it down as a policy so the rule is the same for everyone.

## What is the difference between a column limit and a system limit?

A column limit caps work in one stage and shows which stage is the constraint. A system limit caps all work between the commitment point and delivery, which lets people move freely between stages while still capping total work. The Kanban Guide leaves the form of WIP control to the team, and many teams use both: column limits on the busiest stages and an overall cap.

## How do I convince stakeholders that limits will not slow delivery?

Explain that limits reduce how long each item waits, even if fewer items are started at once. Show them the current count of items in progress and how long those items have been open. Propose a time-boxed trial with an agreed comparison of cycle time before and after. Keep an expedite path for genuine emergencies so stakeholders see that urgent work can still move.

## Why do our limits keep getting overridden?

Usually because there is no agreed path for urgent work, so people treat the limit itself as negotiable. Create a capped expedite lane with a written policy about who may use it. Review every override in your regular cadence and ask what would have prevented it. If overrides are constant, the limit may be set far below real capacity, or intake may be uncontrolled upstream.
