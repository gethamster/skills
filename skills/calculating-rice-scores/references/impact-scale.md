# RICE Impact Scale Reference

The Impact dimension measures how much a single affected user's experience improves.

| Score | Label | Description |
|-------|-------|-------------|
| 3 | Massive | Transforms the experience for the affected user |
| 2 | High | Noticeable, meaningful improvement |
| 1 | Medium | Incremental gain |
| 0.5 | Low | Barely noticeable improvement |
| 0.25 | Minimal | Negligible effect on the user |

## Calibration Tips

- Score two or three obvious initiatives first to establish shared expectations.
- Impact measures per-user effect. A small improvement reaching millions of users is high Reach, not high Impact.
- When in doubt between two levels, pick the lower one. Optimistic Impact compounds with optimistic Reach.

## Source

Intercom's original RICE specification uses this 5-point multiplier scale.
